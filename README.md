# Site NEABI — IFRN Campus Currais Novos

Site público do NEABI do IFRN — Campus Currais Novos.

## Publicar no GitHub Pages
1. Envie todo o conteúdo desta pasta para a raiz de um repositório no GitHub.
2. Confira se `index.html` aparece na raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main** e a pasta **/ (root)**.
6. Salve e aguarde o endereço público aparecer em **Settings → Pages**.

O site usa HTML, CSS e JavaScript puros e não necessita de etapa de build.
