# Protótipos visuais (histórico)

Esta pasta guarda os protótipos visuais usados durante o desenvolvimento do site. Eles **não fazem parte do site**:
nenhuma página oficial depende deles, e esta pasta pode ser apagada ou deixada de fora da publicação sem afetar nada.

- `prototipo-*.html`: páginas de referência (abrem direto no navegador). `prototipo-completo.html` é uma versão em arquivo único.
- `css/` e `js/`: estilo e script usados só por esses protótipos.
- Para funcionar, `prototipo-visual.html` e `prototipo-acoes.html` ainda leem arquivos do site (`../../dados/grupo-estudos.js` e scripts em `../../js/`), por isso a pasta `historico/` deve ficar dentro do projeto se você quiser abri-los.
- Os dados exibidos pelos protótipos são os atuais do site; o conteúdo de exemplo deles é provisório.
